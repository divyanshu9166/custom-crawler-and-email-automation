# Pipeline: everyday use and advanced tools

Everyday view: read the finding, proposed help and intended benefit; review the
recipient and email; save edits. Saving does not send. A published address is not
the same as a verified mailbox or a confirmed decision-maker.

Advanced tools are grouped by purpose, collapsed by default. The page also contains
the expandable **What does each tool do?** reference.

| Control / information | Use |
| --- | --- |

## Email approach

An initial email should briefly state a supported observation, explain specific
implementation we can help with, connect that proposed work to an intended benefit,
and offer one small next step. It must not stop at a performance score or a vague
offer to review a website. The expected benefit remains a goal to test, not an
invented claim of lost leads, guaranteed extra sales or a promised future score.

For the measured Spotless font-loading finding, the proposed work concerns font
loading/fallback behaviour and, where flagged, blocking resource dependencies.
The goal is earlier visible content and a usable path to the existing quote option;
repeat the same lab strategy and check text, icons and relevant page actions.

The focused page keeps mailbox/checker warnings visible. Raw JSON, profiles, source
history and manual qualification are optional advanced views. No approval or sending
guard was removed.
